# Sistema de Recuperação de Informações com VectorDB e RetrievalQA

## Descrição

Projeto desenvolvido utilizando LangChain, FAISS e embeddings para responder perguntas com base em documentos textuais.

O sistema utiliza:
- Embeddings
- Banco vetorial FAISS
- RetrievalQA
- LangChain

---

## Tecnologias

- Python
- LangChain
- FAISS
